# 杨翰宸 · 个人作品集网站

一个本地运行的个人作品集网站，包含个人介绍、技能、项目、实习经历，并提供「坦克大战」游戏的直接启动入口。

## 目录结构

```
作品集/
├── index.html          # 网站主页
├── css/style.css       # 样式
├── js/script.js        # 交互脚本
├── assets/
│   └── 坦克大战.exe     # 坦克大战游戏（可直接运行）
├── 启动网站.bat         # 一键打开网站
└── README.md
```

## 快速开始

### 方式一：直接双击打开（最简单）

双击 `index.html`（或 `启动网站.bat`），即可用默认浏览器打开网站。

### 方式二：本地服务器（更接近真实网站）

在命令行执行：

```bash
cd /d D:\作品集
python -m http.server 8080
```

然后浏览器访问：<http://localhost:8080>

## 「启动坦克大战游戏」按钮说明

点击「🚀 启动坦克大战游戏」按钮会下载 `坦克大战.exe` 到你的下载目录，
**下载后双击即可直接运行**，无需安装 Python 或任何环境。

> 游戏 exe 已打包为独立的单文件可执行程序（Windows），内嵌了游戏资源与中文字体，
> 可在任意 Windows 电脑上直接运行。

## 可选：使用 http://yhc.com 作为本地域名

若希望用 `http://yhc.com` 这样的域名访问（仅本机生效），需要两步：

1. **修改 hosts 文件**（把 `yhc.com` 映射到本机 `127.0.0.1`）：
   - 用管理员身份打开记事本，编辑 `C:\Windows\System32\drivers\etc\hosts`
   - 在末尾添加一行：`127.0.0.1  yhc.com`
   - 保存

2. **在 80 端口启动服务器**（需要管理员权限）：

   ```bash
   python -m http.server 80
   ```

   然后浏览器访问：<http://yhc.com>

> 提示：80 端口需要管理员权限，且不能与其它程序冲突；域名映射仅本机有效，仅用于本地演示。
